# CihuyAkz Studio Lite

Project ini memakai Page Builder dengan dukungan banyak script dalam satu page. Setiap page memiliki **Judul Page**, lalu setiap item di dalamnya memiliki **Nama Script** dan source Lua sendiri.

## Struktur Page
- Judul Page = nama halaman yang tampil di library.
- Nama Script = nama tiap script/tab di dalam halaman.
- Satu page dapat berisi banyak script.
- Admin dapat menambah, mengedit, menghapus, dan mengurutkan item script dari Page Builder.

## Akses
Tidak ada lagi integrasi atau verifikasi Linkvertise. Semua page dibuka langsung sesuai aturan visibility yang sudah ada di aplikasi. Session Owner tetap mengikuti mekanisme login GitHub yang ada.

## Notifikasi
Toast dapat ditutup dengan tombol close maupun langsung disentuh/diklik.
